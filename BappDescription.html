History Explorer searches the proxy history for a literal string or a regular expression and groups every match under the host it came from, so one search answers questions such as which servers are running which software without opening each request in turn. Matches are shown in an expandable per-host tree, one match per row, and can be copied out of the results in whichever shape you need them.

Features

  • See every match grouped under its host, one per row, with a count per host.
  • Search with a literal string or a regular expression, over requests, responses, or both.
  • Cut the history down before searching: status code class, in-scope items only, and included or excluded file extensions (none for paths with no extension).
  • Narrow the results in place as you type, without running the search again.
  • Copy exactly what you need: host and value tab separated for a spreadsheet, the matched values alone, one host's matches, or the whole tree. Copies follow the filter.
  • Show or hide the protocol and port in the host label.
  • Keep working while a search runs, and stop it instantly.

Usage

  1. Open the History Explorer tab and enter a search term, for example Server: .*. Tick the Regular expression option to treat the term as a regex rather than as text.
  2. Choose whether to search requests, responses, or both, and restrict the history by status code, scope, or file extension. Extensions are comma separated, for example js, json.
  3. Press Search. When the search completes, the matches appear grouped under their hosts; press Stop at any point to end it early and keep what has been found.
  4. Type in the Filter results box to narrow the tree, and use Expand all or Collapse all to move through large result sets.
  5. Right-click a host or a match to copy, or press ctrl + c for the selection and ctrl + shift + c for the matched values alone.
